## PUT /api/settings with hideAmounts: "true" (string - should fail)
**Request:** Same as above but with `"hideAmounts": "true"` (string instead of boolean)
**Response: BadRequest (400)**
```json
{
  "code": "VALIDATION_ERROR",
  "message": "Validation failed: hideAmounts: Expected boolean, received string"
}
```

## Validation: PASS
- GET returns hideAmounts: false (default)
- PUT with hideAmounts: true persists correctly
- GET confirms persistence
- PUT with hideAmounts: "true" (string) correctly rejected with 400
