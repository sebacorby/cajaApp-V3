## Observación

El script devuelve `ok: false` y exit code 1 porque no hay servicios corriendo. La rama `-Stop` no tolera una colección vacía de PIDs al enlazar `StoppedPids`. Esto no es bloqueante para esta validación porque no hay servicios que detener y por tanto no hay estado residual que apagar.

Adicionalmente se inspeccionaron los puertos administrados (3000 frontend, 11436 backend) y no había procesos escuchando:

```
Get-NetTCPConnection -State Listen | Where LocalPort -in (3000,11436)
(sin resultados)
```

El único proceso `node` activo en el host pertenece a otra aplicación (`kimi-desktop`, PID 54116) y no es del proyecto CajaApp V3.

## Decisión

No se reintenta el comando. No se modifica el script (prohibido por §4). Se documenta el comportamiento y se continúa con §7.5 (restauración de SQLite) y §14 (cleanup).
